# Excel Data Cleaning & Analysis Tool

## Features

- Load Excel/CSV/JSON files
- Remove duplicates
- Handle missing values
- Standardize column names
- Analyze datasets
- Group analysis
- Sorting
- Filtering
- Searching
- Data profiling
- Email validation
- Data visualization
- PDF report generation
- Excel formatting
- Multiple file processing
- GUI support
- Logging system

## Installation

pip install -r requirements.txt

## Run CLI Version

python main.py

## Run GUI Version

python gui/app_gui.py
